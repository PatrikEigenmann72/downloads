About bin/pmake
----------------
This source release bundles a prebuilt pmake binary (bin/pmake, or bin/pmake.exe
on Windows) so you can build this project without installing pmake separately
first. It's a prebuilt, unsigned binary, so the first time you run it, your OS
will flag it the same way it flags any unsigned executable: on macOS, Gatekeeper
blocks it until you approve it once via System Settings > Privacy & Security >
Open Anyway; on Windows, SmartScreen blocks it until you click "More info" >
"Run anyway".

If you'd rather not run it at all, you don't have to. <project>/<project>.pmake
is a plain text build recipe, not a binary - open it and read its comp=, flags=,
src= and libs= lines to see exactly which compiler, flags, and source files this
project needs, then stitch together your own gcc/clang command line by hand (or
feed the same information to whatever build tool you prefer) instead of running
the bundled pmake at all.
